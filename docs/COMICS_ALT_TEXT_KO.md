# Rescue79 설명 만화 대체텍스트

이 문서는 `docs/comics`에 있는 여섯 장의 설명 만화를 보지 못하는 사용자와
화면낭독기 이용자를 위한 글 설명입니다. 그림 속 수치와 표현보다 README와
`MODEL_CARD.md`의 최신 텍스트가 우선합니다.

각 이미지는 검은색과 빨간색을 중심으로 한 카드뉴스형 만화이며, 빨간 목수건을 한
검정·흰색 고양이가 설명자 역할을 합니다.

## 1. `01_problem.png` — 사고보다 무서운 발견 지연

### 짧은 대체텍스트

> 복도에서 넘어진 고령자를 CCTV가 촬영하지만 여러 화면을 보는 관제요원이 즉시
> 발견하기 어려운 상황과, AI가 후보를 먼저 보여 주되 자동 신고·출동은 하지
> 않는다는 원칙을 설명하는 고양이 만화.

### 자세한 그림 설명

상단 제목은 “사고보다 무서운 발견 지연”이며, “CCTV가 있어도 모든 화면을 계속 볼
수는 없어요”라는 문장이 있습니다.

가운데에는 복도 바닥에 넘어진 고령자와 옆의 휠체어, 벽에 설치된 CCTV가 보입니다.
오른쪽 말풍선에는 간단한 사람 자세 그림과 `7→9→7→9`, “구조수신호 후보”라는
표시가 있습니다.

아래에는 여러 CCTV 모니터를 보는 관제요원이 있고, 넘어진 사람이 있는 화면 하나가
빨간 테두리와 느낌표로 강조됩니다. 고양이는 지시봉을 들고 “AI는 후보를 먼저
찾아줘요!”라고 말합니다. 맨 아래에는 “AI 자동 신고·출동 아님”이라는 안전 문구가
크게 표시됩니다.

### 핵심 메시지

- 목표는 사람이 놓칠 수 있는 후보를 더 빨리 살펴보게 돕는 것입니다.
- AI가 실제 구조상황을 확정하거나 자동 신고·출동하는 것은 아닙니다.

## 2. `02_solution.png` — 해결은 후보를 먼저 띄우기

### 짧은 대체텍스트

> CCTV 정지영상에서 COCO-17 관절을 찾고 hard4가 D7·D9 후보를 표시한 뒤,
> 원본과 오버레이를 관제요원이 검토하는 흐름과 자동 112·119 신고가 꺼져 있음을
> 설명하는 고양이 만화.

### 자세한 그림 설명

상단 제목은 “해결은 후보를 먼저 띄우기”입니다. 위쪽에 다섯 칸의 흐름도가
왼쪽에서 오른쪽으로 이어집니다.

1. CCTV 정지영상: 복도에서 넘어진 사람 사진
2. COCO-17 관절 추출: 색 점과 선으로 된 사람 뼈대
3. hard4 D7·D9 후보: D7과 D9 관절 오버레이 예시
4. 원본·오버레이: 원본 사진과 관절선 사진을 나란히 비교
5. 관제요원 검토: 사람이 모니터를 확인

고양이는 “정적 모델은 한 장씩 판별해요!”라고 말합니다. 오른쪽 안내상자에는
“정적 7·9 판별기로 검토”, “한 장씩 결과 확인”, “자동 112·119 신고 OFF”가
적혀 있습니다.

맨 아래 점선 상자는 미래 단계입니다. 여러 연속 프레임, 시간 기반 확인, 신뢰도
상승과 최종 확인으로 이어지는 그림이 있지만 현재 기능이 아니라 추후 연구임을
나타냅니다.

### 핵심 메시지

- 현재 공개판은 정지사진을 한 장씩 검토합니다.
- 원본과 관절 오버레이를 사람이 확인합니다.
- 자동 신고 기능은 없습니다.

## 3. `03_training.png` — hard4는 이렇게 학습했어요

### 짧은 대체텍스트

> 합성 관절 15,840 윈도로 학습된 기반 TCN에 생성형 정지사진 34장과 사진당 32개
> 증강을 사용하고, 17개 관절을 48프레임 정지 반복해 7·9 출력부만 80 epoch
> 보정한 과정을 설명하는 고양이 만화.

### 자세한 그림 설명

상단 제목은 “hard4는 이렇게 학습했어요”입니다.

첫 번째 줄에는 “기반 TCN: 합성 관절 15,840 윈도”라는 설명과 여러 관절 뼈대,
TCN 기계 그림이 있습니다. 오른쪽에는 정지영상 34장이 D7 16장, D9 18장으로
나뉘어 표시됩니다.

두 번째 줄은 “장당 32개 증강 = 1,088 입력”입니다. 같은 원본의 자세를 조금씩
돌리거나 옮긴 여러 사진이 컨베이어벨트 위에 놓여 있습니다. 오른쪽에는 COCO-17
관절 그림과 “17개 관절 → 48프레임 정지 반복”이 표시됩니다.

세 번째 줄에는 “7·9 출력부만 보정·80 epoch”라고 적혀 있으며 D7과 D9 관절 예시가
각각 빨간색과 초록색으로 나뉩니다. 고양이는 엄지를 들고 “1,088장은 원본 수가
아니에요!”라고 말합니다. 하단 강조문은 “정적 자세 중심 학습”입니다.

### 핵심 메시지

- 독립 원본은 1,088장이 아니라 생성형 정지사진 34장입니다.
- 1,088은 사진마다 32개 변형을 적용한 학습 입력 수입니다.
- 실제 움직임이 아니라 정지 관절을 48프레임 동안 반복했습니다.
- 기반망 전체가 아니라 7·9 출력 부분을 제한적으로 조정했습니다.

## 4. `04_performance.png` — 어디까지 맞혔나?

### 짧은 대체텍스트

> 생성형 CCTV 정지영상 50장에서 D7 25/25와 D9 25/25를 맞혔지만 같은 50장
> 재실행은 독립 150장 시험이 아니며, 실제 CCTV 검출률·오경보율은 미측정이고
> 점수도 정답 확률이 아님을 강조하는 고양이 만화.

### 자세한 그림 설명

상단 제목은 “어디까지 맞혔나?”입니다. 가운데에 “생성형 CCTV 정지영상 50/50”이
매우 크게 적혀 있습니다. 아래는 D7과 D9 두 영역으로 나뉩니다.

- 왼쪽 빨간 D7 영역: 넘어진 사람이 한 팔을 옆으로 뻗은 사진과 25/25
- 오른쪽 검은 D9 영역: 넘어진 사람이 한 손을 머리에 댄 사진과 25/25

아래쪽에서 경고 표지판을 든 고양이가 다음 제한사항을 가리킵니다.

- 같은 50장 재실행도 동일
- 150장 독립시험 아님
- 합성 정지영상 100%는 실제 CCTV 100%가 아님
- 실제 CCTV 검출률·오경보율 미측정

오른쪽 큰 말풍선에는 “점수는 정답 확률이 아니에요!”라고 적혀 있습니다.

### 핵심 메시지

- 사전 고정 생성형 정지사진 50장에서는 50장을 구분했습니다.
- 반복 실행은 재현성 확인이지 새로운 독립 표본 증가가 아닙니다.
- 실제 CCTV 성능과 오경보율은 아직 알 수 없습니다.

## 5. `05_safe_rollout.png` — 배포는 이렇게 안전하게

### 짧은 대체텍스트

> hard4 통합부터 실제 7979 연속영상, 비신호 오경보, 속도·지연·camera-hour
> 측정, 자동출동 없는 shadow pilot까지 다섯 단계로 올라가며 최종 판단은 항상
> 사람이 한다는 안전 배포 계획을 설명하는 고양이 만화.

### 자세한 그림 설명

상단 제목은 “배포는 이렇게 안전하게”입니다. 돌계단 다섯 개가 왼쪽 아래에서
오른쪽 위로 올라갑니다.

1. hard4 어댑터 통합
2. 실제 7979 연속영상 시험
3. 전화·손흔들기 등 오경보 시험
4. 속도·지연·camera-hour 측정
5. 자동출동 없는 shadow pilot

빨간 화살표가 첫 계단에서 마지막 계단까지 이어지고, 맨 위에는 빨간 깃발이
있습니다. 고양이는 “현장 시험 뒤 관제 보조로 시작해요!”라고 말합니다.

오른쪽 아래에는 여러 CCTV를 보는 관제요원 그림과 “최종 판단은 항상 사람”이라는
큰 안내가 있습니다.

### 핵심 메시지

- 현재 정적 50장 결과만으로 현장 배포를 완료했다고 말하지 않습니다.
- 실제 시간축과 강한 비신호 사례를 먼저 시험해야 합니다.
- 현장에서는 자동출동 없이 사람 검토 보조부터 시작해야 합니다.

## 6. `06_verification.png` — 검증 기록도 함께 봐요!

### 짧은 대체텍스트

> 실제 로컬 7·9 모델 검토기 화면, D7·D9 원본과 관절 오버레이 예시, 사전 고정
> 50장의 결과표를 함께 보여 주며 생성형 정지영상 50/50과 실제 CCTV 검출률·
> 오경보율 미측정을 구분하는 검증 기록 만화.

### 자세한 그림 설명

상단 제목은 “검증 기록도 함께 봐요!”이며 고양이가 지시봉을 들고 있습니다.

첫 번째 큰 영역은 “판별기 실행 화면”입니다. 어두운 색의 로컬 7·9 모델 검토기
화면 캡처가 들어 있습니다. 모델 선택, 정답과 이미지 선택, 원본·관절 오버레이,
모델 결과값이 한 화면에 보입니다.

두 번째 영역은 “D7·D9 결과 예시”입니다.

- D7 25/25: 한 팔을 옆으로 뻗은 원본과 노란 관절 오버레이
- D9 25/25: 한 손을 머리에 댄 원본과 노란 관절 오버레이

세 번째 영역은 “사전 고정 50장 결과표”로, 50개의 작은 관절 오버레이가 초록색
테두리의 격자 형태로 정리돼 있습니다.

오른쪽 아래의 고양이는 엄지를 들고 “캡처와 결과 파일을 함께 남겼어요!”라고
말합니다. 그 아래에는 두 안내가 있습니다.

- 확인 완료: 생성형 정지영상 50/50
- 아직 미측정: 실제 CCTV 검출률·오경보율

### 핵심 메시지

- 성능 숫자만이 아니라 실행 화면, 오버레이와 전체 결과표를 함께 확인했습니다.
- 이 증빙도 생성형 정지사진 범위이며 실제 CCTV 현장 근거는 아닙니다.

## 전체 만화의 한 문장 요약

> Rescue79 hard4는 생성형 7·9 정지사진을 한 장씩 검토하는 연구 모델이며,
> 사전 고정 50장에서는 50장을 구분했지만 실제 CCTV 검출률·오경보율과 완전한
> 7979 시간축은 아직 검증하지 않았고 최종 판단과 신고는 항상 사람이 담당합니다.
