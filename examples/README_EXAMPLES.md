# 예제 이미지 안내

이 폴더의 두 이미지는 **실제 CCTV 사진이 아니라 생성형 AI로 만든 합성 시험 이미지**입니다. 실제 인물이나 실제 사고를 촬영한 자료가 아니며, 개인정보가 포함된 실제 CCTV 원본으로 취급해서는 안 됩니다.

## 들어 있는 파일

- `d7_generated_example.png`: `DIGIT_7` 의도를 주고 만든 합성 정지영상 예제
- `d9_generated_example.png`: `DIGIT_9` 의도를 주고 만든 합성 정지영상 예제

두 파일은 사전 고정한 50장 생성형 CCTV 정지영상 평가 세트의 첫 번째 D7·D9 사례입니다. 원본 평가 세트는 모델 평가 전에 고정되었고, 각 이미지는 한 번만 생성했으며 재생성하거나 결과를 보고 골라내지 않았습니다.

- D7 원본 SHA-256: `e809ea30f687dbe38a8fbcd9602822318a918b4b7ce68e90cc5d2a1f36757732`
- D9 원본 SHA-256: `2041a98aed0ba738fc00e4fa0bd14eeff659ec75e71a2339a2e1e60ead81d351`

## 이렇게 사용하세요

1. 판별기 화면이 정상적으로 열리는지 확인합니다.
2. D7 파일에는 기대값 `7`, D9 파일에는 기대값 `9`를 선택합니다.
3. 원본과 관절 오버레이를 나란히 보고 사람이 결과를 확인합니다.

이 예제는 설치 확인과 화면 사용 연습에 적합합니다. 공개된 뒤에는 더 이상 새로운 비공개 holdout으로 간주할 수 없으므로, 후속 성능 시험의 독립 평가자료로 재사용하지 마세요.

## 꼭 알아둘 한계

- 파일의 `DIGIT_7`·`DIGIT_9`는 생성 프롬프트의 의도이며 사람의 실제 구조 요청을 뜻하지 않습니다.
- 정지영상 두 장으로 `7→9→7→9` 시간 순서, 실제 CCTV 검출률, 오경보율 또는 현장 성능을 증명할 수 없습니다.
- 합성 이미지에서 나온 결과를 실제 사람·야간·원거리·가림·다중 인물 환경으로 일반화하면 안 됩니다.
- 이 프로그램의 결과는 사람이 검토해야 하며 자동 112·119 신고나 출동 판단에 사용하면 안 됩니다.

실제 사람의 사진이나 CCTV 화면을 시험할 때는 촬영·처리 권한, 당사자 고지, 최소 수집, 보존기간과 삭제 절차를 먼저 확인하세요.
