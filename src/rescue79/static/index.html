사진 한 장의 7·9 자세를 함께 확인해요

정답을 알고 있는 시험사진으로 모델을 점검하는 로컬 연구 도구입니다.

중요: 이 도구는 구조 요청을 확정하지 않고 112·119에 신고하지 않습니다. 실제 위험하면 프로그램을 기다리지 말고 사람이 직접 확인하고 필요한 기관에 연락하세요.
1정답 7 또는 9 선택
2사진 한 장 선택
3검토 시작 누르기
4원본과 관절선 확인

1. 사진의 정답은 무엇인가요?

모델을 시험하는 도구이므로 내가 이미 알고 있는 정답을 먼저 고릅니다.

2. 사진을 골라 주세요

아직 선택한 사진이 없습니다.

한 사람의 머리·몸·양팔이 밝고 크게 보이는 PNG, JPG, WEBP 사진이 좋습니다.

모델 상태를 확인하는 중입니다…

4. 결과를 원본과 함께 확인하세요

내가 고른 정답
모델의 첫 번째 결과
관절 품질
찾은 사람 수
보인 관절 수
비보정 순위 점수
점수가 0.99여도 “정답 확률 99%”나 “구조 요청 확률 99%”라는 뜻이 아닙니다. 모델이 여러 답 중 무엇을 더 높게 보았는지 나타내는 비보정 순위 점수입니다.

결과의 쉬운 뜻

  • 정답: 모델 결과와 내가 고른 정답이 같습니다. 관절선도 맞는지 봅니다.
  • 오답: 모델 결과가 다릅니다. 사진과 결과를 시험 기록으로 남깁니다.
  • 판정 보류: 사람 또는 관절 정보가 부족합니다. 억지로 답을 만들지 않은 정상 동작입니다.
